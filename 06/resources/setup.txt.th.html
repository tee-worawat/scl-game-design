ครูตรวจและติดตั้งก่อนคาบ

GAME DESIGNER · ชุด Python บนคอมพิวเตอร์
ใช้ Python 3.12 และ pygame-ce 2.5.8 ตามสภาพแวดล้อมทดสอบ
ครูต้องติดตั้งและลองบนระบบของห้องเรียนก่อนคาบ เวอร์ชันอื่นยังไม่ยืนยัน

แตก ZIP ทั้งชุด เก็บ starter.py, studio.py, images/ และ fonts/ ไว้ด้วยกัน
เปิดเทอร์มินัลในโฟลเดอร์ที่แตกไฟล์
Windows: py -3.12 -m venv .venv
macOS/Linux: python3.12 -m venv .venv
ติดตั้งบน Windows: .venv\Scripts\python -m pip install -r requirements.txt
ติดตั้งบน macOS/Linux: .venv/bin/python -m pip install -r requirements.txt
รันบน Windows: .venv\Scripts\python starter.py
รันบน macOS/Linux: .venv/bin/python starter.py

ติดตั้งครั้งแรกต้องมีอินเทอร์เน็ตและสิทธิ์ติดตั้ง หลังจากนั้นเกมเล่นในเครื่องได้ ไม่ต้องมีบัญชีหรืออินเทอร์เน็ต ไม่สมมติว่ารองรับเครื่องที่ใช้ได้เฉพาะเบราว์เซอร์/Chromebook
อย่าตั้งชื่อไฟล์ว่า pygame.py เก็บชุดที่ทดสอบแล้วสำหรับผู้เรียนที่ตามไม่ทัน

ปุ่มลูกศรเริ่มใช้บท 2 ปุ่ม R รีเซ็ตตั้งแต่บท 4 Esc หรือปิดหน้าต่างเพื่อออก
กด H ดูกรอบชนผู้เล่น 48×48 ภาพปรับขนาดเฉพาะตอนวาด ไม่แก้ PNG ต้นฉบับ
บท 1 เป็นฉากนิ่ง บท 1–3 เริ่มใหม่ด้วยการปิดแล้วรันอีกครั้ง
แต่ละบทเป็นจุดฝึกแนวคิดแยก ไม่ได้สะสมทุกกลไกก่อนหน้าเสมอ บท 6–10 ไม่มีจับเวลา บท 8 เป็นต้นไปไม่มีลาดตระเวน เพื่อเน้นข้อมูลและออกแบบ

studio.py เป็นโครงสร้างที่ครูเตรียมให้ ดูแลหน้าต่าง เหตุการณ์ dt ภาพ ฟอนต์ และตัวช่วยตรวจชน ไม่ใช่หลักฐานว่าผู้เรียนเขียนเอง ผู้เรียนแก้ starter.py บทเตรียม 00 แนะนำคลาสง่าย ๆ และออบเจ็กต์แยกกัน บทกราฟิกใช้ฟังก์ชัน ไม่ต้องใช้ inheritance ฟิสิกส์ หรือไวยากรณ์ Unity
ข้อความในเกมและชื่อในโค้ดเป็นอังกฤษ คู่มือเป็นสองภาษา ตอบอธิบายภาษาไทยได้
