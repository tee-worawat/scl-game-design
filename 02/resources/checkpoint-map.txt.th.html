จากไฟล์เดียวสู่โมดูล: แผนจุดตรวจ

วางข้างตัวแก้โค้ดขณะเปลี่ยนโครงสร้าง

แผนจุดตรวจ
1. main.py: ฉากนิ่งผู้เรียน -> เขียนเคลื่อนที่และเส้นทางพื้นหลัง ครูอ้างอิง 01_loop.py
2. 02_functions.py: ตั้งชื่องานในไฟล์เดิม ย้ายโค้ดของตน บันทึก my_loop.py ก่อน
3. 03_player.py: Player มี x/y/speed/image ของตน ปรับ move บันทึก my_functions.py ก่อน ครูอ้างอิง main.py
4. modular/main.py + scene.py: import เฉพาะ helper ฉากสองตัว คงคลาสและลูปใน main บันทึก my_player.py ก่อน
เทียบพฤติกรรมหลังจัดโครงทุกครั้ง อย่าทับสำเนาเดียวที่รันได้
5. คาบเชื่อม SPRITE (แยก 45 นาทีก่อนบท 03): python 04_sprites.py ผู้เรียนได้การเคลื่อนที่/ตั้งค่าจากบทเดิม เติม TODO if/elif ทิศและการเลือกค่าจาก dictionary ครูมีเฉลยครบ เริ่มหันลง ลูกศรขยับ/หัน ปล่อยจำทิศ แนวตั้งชนะเดินเฉียง ขวา/ลงชนะปุ่มตรงข้าม เมื่อชนขอบยังหันตามอินพุตแม้ตำแหน่งถูกจำกัด Escape/ปิดเพื่อออก รันใหม่รีเซ็ต โหลดภาพสี่รูปครั้งเดียว วาดตรงกลางกรอบ 64px dictionary จับคู่ชื่อทิศกับภาพ ยังไม่ใช้ inheritance หรือแอนิเมชันเดิน
