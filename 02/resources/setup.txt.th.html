ติดตั้งครั้งเดียวในสภาพแวดล้อม Python: python -m pip install -r requirements.txt
รันด้วยคำสั่ง python จากสภาพแวดล้อมเดียวกัน ทดสอบกับ pygame-ce 2.5.8
อย่าตั้งชื่อไฟล์ pygame.py รันจากเทอร์มินัล ไม่ใช่เบราว์เซอร์

เส้นทางผู้เรียน (main.py เริ่มเป็นฉากนิ่งที่รันได้):
1. python main.py — เติมการเคลื่อนที่และเส้นทางพื้นหลังตรง TODO
2. บันทึกเป็น my_loop.py อ่าน 02_functions.py แล้วย้ายโค้ดของตนเข้า helper เมื่อพร้อมใช้เป็น main.py
3. บันทึก my_functions.py ใช้ 03_player.py เป็น main.py ถัดไป ปรับโค้ดเคลื่อนที่ของตนเข้า Player.move constructor และ draw เป็นโครงช่วย
4. บันทึก my_player.py นำเมธอดที่ทำเสร็จไป modular/main.py ย้าย helper สองฟังก์ชันไป modular/scene.py แทน TODO แล้วรัน python modular/main.py ขั้นนี้จงใจแจ้ง NotImplementedError จนกว่าจะย้าย helper

เส้นทางครู:
python 01_loop.py -> python 02_functions.py -> python main.py -> python modular/main.py
ทุกจุดตรวจของครูรันได้แยก main.py คือ Player แบบไฟล์เดียว reference.py และ starter.py ใช้เปิด main.py ส่วน teacher_example.py เปลี่ยนความเร็วเป็น 240
