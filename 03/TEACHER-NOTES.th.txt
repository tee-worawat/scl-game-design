03 · เก็บไอเทมเพียงครั้งเดียว

แตกชุดผู้เรียนทั้งหมดและทำตามไฟล์ติดตั้งบนเครื่องห้องเรียน

รัน reference.py ของครู ตรวจผลที่คาด แล้วทดลอง teacher_example.py แยก starter.py ผู้เรียนมี TODO โดยตั้งใจ

ซ่อนบันทึกและเฉลยจากจอฉาย แสดงหน้าต่าง Python จริงในช่วงทดลอง

พิมพ์ใบไล่ค่า/ลองเล่น เตรียมทางเลือกกระดาษและกำหนดสลับบทบาท


เล่น · เชื่อมความรู้และเตรียม (8 min)

ทบทวนการเคลื่อนที่และ if เชื่อม True/False และ not ด้วยบัตรเก็บแล้ว

PROMPT: ส่วนไหนอธิบายได้แล้ว?

ANSWER: ทบทวนการเคลื่อนที่และ if เชื่อม True/False และ not ด้วยบัตรเก็บแล้ว

EVIDENCE: ฟังคำอธิบายเหตุและผลที่โยงกับตัวแปร เงื่อนไข หรือบรรทัด ตรวจแต่ละคนแยกกัน


คาดการณ์ · อ่านก่อนรัน (8 min)

ซ่อนผล ให้คิดเงียบ 2 นาที อธิบายเป็นคู่ 3 นาที และฟังคำทำนายรายคน 3 นาที

PROMPT: หลังแตะคริสตัลและหยุดทับอยู่ collected จะเปลี่ยนซ้ำไหม? เมื่อเดินออกภาพจะกลับมาหรือไม่?

ANSWER: collected เปลี่ยน False เป็น True ครั้งเดียว คริสตัลซ่อนจนเปิดใหม่ การชนใช้สี่เหลี่ยม 48×48 ไม่ใช่พิกเซลทึบของภาพ

EVIDENCE: ฟังคำอธิบายเหตุและผลที่โยงกับตัวแปร เงื่อนไข หรือบรรทัด ตรวจแต่ละคนแยกกัน


ทดลอง · เทียบกับที่คิด (8 min)

ครูเปิด reference.py ที่ยังไม่แก้จากชุดครู ผู้เรียนสังเกตโค้ดที่ทำงาน แล้วเขียนโครง TODO แยก ตาม SETUP.th.txt ทดลอง 3 นาที เทียบ 3 นาที และรีเซ็ต 2 นาที ซ่อน teacher_example.py

PROMPT: หลังแตะคริสตัลและหยุดทับอยู่ collected จะเปลี่ยนซ้ำไหม? เมื่อเดินออกภาพจะกลับมาหรือไม่?

ANSWER: collected เปลี่ยน False เป็น True ครั้งเดียว คริสตัลซ่อนจนเปิดใหม่ การชนใช้สี่เหลี่ยม 48×48 ไม่ใช่พิกเซลทึบของภาพ

EVIDENCE: ฟังคำอธิบายเหตุและผลที่โยงกับตัวแปร เงื่อนไข หรือบรรทัด ตรวจแต่ละคนแยกกัน


สำรวจ · อธิบายกติกา (16 min)

แสดงชุดเริ่มต้นจริงก่อนรัน ให้แต่ละคนอธิบาย ไม่ใช่อ่านโค้ดตามตัว สลับคนพิมพ์/คนนำทางเมื่อผ่านครึ่งเวลา เชื่อมเงื่อนไขชนกับ collected=True และเงื่อนไขวาด not collected กด H ดูกรอบชนของผู้เล่นและอธิบายว่าภาพกับกรอบชนต่างกันได้

PROMPT: หาก collected เป็น True แล้วและหุ่นยนต์กลับไปตำแหน่งเดิม จะเข้าเงื่อนไขหรือไม่? อธิบายทั้งสองส่วน

ANSWER: ไม่เข้า เพราะ not collected เป็น False เงื่อนไข and จึงไม่ผ่านแม้ touching เป็น True

EVIDENCE: ฟังคำอธิบายเหตุและผลที่โยงกับตัวแปร เงื่อนไข หรือบรรทัด ตรวจแต่ละคนแยกกัน


ปรับแก้ · เปลี่ยนพฤติกรรมหนึ่งอย่าง (15 min)

แสดงชุดเริ่มต้นจริงก่อนรัน ให้แต่ละคนอธิบาย ไม่ใช่อ่านโค้ดตามตัว สลับคนพิมพ์/คนนำทางเมื่อผ่านครึ่งเวลา ย้ายคริสตัลจาก (560,300) ไป (560,440) ทั้งโค้ดตรวจชนและวาดภาพ

PROMPT: ย้ายคริสตัลจาก (560,300) ไป (560,440) ทั้งโค้ดตรวจชนและวาดภาพ

ANSWER: ใช้ตัวอย่างครูหลังผู้เรียนลองแล้ว ตรวจว่ากติกาที่ขอเปลี่ยนจริงและยังเริ่มใหม่ได้

EVIDENCE: ฟังคำอธิบายเหตุและผลที่โยงกับตัวแปร เงื่อนไข หรือบรรทัด ตรวจแต่ละคนแยกกัน


สร้าง · ตัดสินใจออกแบบเอง (25 min)

วางแผน 5 นาที สร้าง 12 สลับทดสอบ 5 และบันทึก 3 ลดขอบเขตก่อนเพิ่มกลไกใหม่ ออกแบบภารกิจเก็บหนึ่งชิ้นในตำแหน่งที่เลือก ผู้เล่นใหม่ต้องรู้เป้าหมายและเห็นว่าไอเทมหายเพียงครั้งเดียว

PROMPT: ออกแบบภารกิจเก็บหนึ่งชิ้นในตำแหน่งที่เลือก ผู้เล่นใหม่ต้องรู้เป้าหมายและเห็นว่าไอเทมหายเพียงครั้งเดียว

ANSWER: คำตอบมีหลายแบบ ต้องมีเป้าหมาย การเปลี่ยนกติกา และหลักฐานจากทดสอบ เปลี่ยนภาพอย่างเดียวไม่พอ

EVIDENCE: ฟังคำอธิบายเหตุและผลที่โยงกับตัวแปร เงื่อนไข หรือบรรทัด ตรวจแต่ละคนแยกกัน
